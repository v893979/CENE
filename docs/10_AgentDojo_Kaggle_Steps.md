# 10 — Running the AgentDojo matrix on Kaggle (run setup r3)

Notebook: `notebooks/agentdojo_cene.ipynb` (generated by `cene_agentdojo/make_notebook.py`). Settings:
`cene_agentdojo/run_config.yaml`. Policy tag `agentdojo-policy-v1` (unchanged); run-setup tag `agentdojo-run-r3`.
The kaggle CLI is not used; everything is done in the Kaggle web UI.

## 1. Build the repo zip (on this machine)

```bash
bash cene_agentdojo/package_kaggle.sh
```

Writes `dist/cene-agentdojo-policy-v1.zip` from tag `agentdojo-run-r3`, with `REVISION.json` recording both tags
and commits; it refuses if the policy files differ from `agentdojo-policy-v1`.

## 2. New Dataset version

Kaggle → Datasets → `cene-agentdojo-policy-v1` → **New Version** → delete the old file → upload the new zip → note
`run setup r3` → Create. `REVISION.json` must show `"run_tag": "agentdojo-run-r3"`.

## 3. Notebook

Import the new `notebooks/agentdojo_cene.ipynb` (File → Import Notebook; a fresh notebook is cleanest). GPU T4 x2,
Internet on. Inputs: dataset `cene-agentdojo-policy-v1` (latest version); model `gemma-4-12b-it` (and
`gemma-4-e4b-it` as the last fallback).

## 4. CHECK (under 40 min)

First cell: `SESSION = "CHECK"`, others as they are. Run All. It serves `hf-12b`, sends one request, then runs the
mode selection (native → local/tool → local/user) on user tasks 0, 3, 6 under M1, and prints per episode: utility,
tool calls, parse failures, model calls, seconds; plus the week-1/week-2 plan.

Download: `check.json`, `tool_mode.json`, `select_*.json`, `environment_CHECK.json`, `serve_info.json`,
`server.log`. If it stops at "no tool-calling mode qualifies", that is the result: send the same files.

## 5. RUN sessions

Make a private dataset `cene-agentdojo-outputs` holding every earlier output file (at least `check.json`,
`tool_mode.json`, `select_*.json`; later also `smoke.json`, `agentdojo_M*.json`), new version each time, and attach it.
First cell: `SESSION = "RUN"`, `WEEK = 1` (or `2` after the reset), `QUOTA_LEFT_HOURS` = the hours Kaggle shows as
left. **Save & Run All (Commit).** The first RUN runs the smoke (stops itself if 2+ of 3 M1 smoke episodes made no
tool call). Each RUN starts no new episode after min(11 h, quota left − 1.5 h) and writes `status.json`; repeat
within the week until `"_week_done": true`, then after the reset run `WEEK = 2` until `"_all_done": true`.

## 6. Hand back

After each session download everything in `/kaggle/working` (except `repo/`) into
`docs/results/agentdojo/kaggle/<SESSION>-<n>/`, including failed or partial runs, with the notebook version number.
Earlier records: r1 S1 → `kaggle/S1-v1-r1/`; r2 CHECK → `kaggle/CHECK-v2-r2/` (currently in `outputs/Kaggle/v2`).
